# Space Shuttle model

The simulator uses NASA’s Space Shuttle (D) model for the exterior flight camera. The distributed GLB preserves the geometry, textures, and materials of the original. The previous simulator converted the source GLB in Blender to remove Draco compression and use JPEG textures.

- [NASA 3D Resources](https://github.com/nasa/NASA-3D-Resources)
- [Original model directory at revision 11ebb4ee0437](https://github.com/nasa/NASA-3D-Resources/tree/11ebb4ee0437/3D%20Models/Space%20Shuttle%20%28D%29)
- [NASA images and media usage guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/)

The included GLB has SHA-256 `3a486bc0405f85c4b02b29d42286b318c60331dd064ad4b75bcb56423373634a`. The source GLB has SHA-256 `d0015681ff092d36062fdfed78e2bd1ca0f86e90862840d25bae11c686ce3549`. The simulator depicts the original spacecraft markings in context.
